# WikiMatch-Page

Static support and privacy pages for the WikiMatch app.

## Files

- `index.html`: support and contact page
- `privacy.html`: privacy policy
- `styles.css`: shared styles

## Publish With GitHub Pages

1. Push this repository to GitHub.
2. Open `Settings` in the GitHub repository.
3. Go to `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and the `/ (root)` folder.
6. Save, then wait for GitHub Pages to finish publishing.

Once published, the pages should be available at:

- `https://candobear.github.io/WikiMatch-Page/`
- `https://candobear.github.io/WikiMatch-Page/privacy.html`
